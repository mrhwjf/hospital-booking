# Glossary (Thuật ngữ)

| Thuật ngữ | Mô tả |
|---|---|
| `BENHNHAN` | Vai trò bệnh nhân sử dụng hệ thống để đặt lịch và theo dõi hồ sơ cá nhân. |
| `BACSI` | Vai trò bác sĩ thực hiện khám, cập nhật phiếu khám, chỉ định và kê đơn. |
| `NHANVIEN` | Vai trò lễ tân/nhân viên y tế hỗ trợ vận hành đặt lịch và check-in. |
| `ADMIN` | Vai trò quản trị hệ thống, quản lý dữ liệu nền và phân quyền. |
| `lich_hen` | Bản ghi lịch hẹn khám giữa bệnh nhân và bác sĩ theo ngày/khung giờ. |
| `khung_gio_kham` | Khung giờ khám cụ thể (trống/đã đặt/khóa) theo lịch làm việc bác sĩ. |
| `lich_lam_viec` | Ca làm việc mẫu (template) theo thứ trong tuần. |
| `lich_lam_viec_bac_si` | Bảng gán ca làm việc cho bác sĩ theo ngày thực tế. |
| `phieu_kham` | Hồ sơ khám trong một lần tiếp nhận/khám bệnh. |
| `dich_vu_lich_hen` | Bảng liên kết các dịch vụ/gói khám được chọn trong một lịch hẹn. |
| `goi_kham` | Nhóm dịch vụ y tế đóng gói sẵn. |
| `dich_vu` | Dịch vụ y tế đơn lẻ (khám, xét nghiệm, chẩn đoán hình ảnh...). |
| `ly_do_huy` | Danh mục lý do hủy lịch theo ngữ cảnh (bệnh nhân/bác sĩ/hệ thống). |
| `icd10` | Danh mục mã chẩn đoán chuẩn quốc tế dùng cho phiếu khám. |
| `RBAC` | Phân quyền theo vai trò và quyền chi tiết (Role-Based Access Control). |
| `walk-in` | Bệnh nhân đến trực tiếp chưa có lịch đặt trước. |
| `dang_cho` | Trạng thái lịch hẹn mới tạo, đang chờ xử lý tiếp theo. |
| `da_thanh_toan` | Trạng thái lịch hẹn đã ghi nhận thanh toán. |
| `da_xac_nhan` | Trạng thái lịch hẹn đã được xác nhận bởi cơ sở y tế. |
| `da_hoan_tat` | Trạng thái lịch hẹn đã hoàn thành khám. |
| `da_huy` | Trạng thái lịch hẹn đã hủy. |
| `khong_den` | Trạng thái bệnh nhân không đến khám theo giờ hẹn. |
