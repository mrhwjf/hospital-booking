# Local Setup

## Backend
1. Vao thu muc `backend`
2. Chay `composer install`
3. Tao file `.env` tu `.env.example`
4. Cau hinh DB
5. Chay migration/seed
6. Chay `php artisan serve`

## Frontend
1. Vao thu muc `frontend`
2. Chay `npm install`
3. Cau hinh `VITE_API_BASE_URL`
4. Chay `npm run dev`

## Script tham khao
- `scripts/setup-dev.ps1`
- `scripts/import-schema.ps1`
- `scripts/run-backend-tests.ps1`
- `scripts/run-frontend-tests.ps1`
