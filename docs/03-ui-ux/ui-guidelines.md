# UI Guidelines

## Mục tiêu giao diện
- Tin cậy, rõ ràng, dễ thao tác trong ngữ cảnh y tế.
- Tối ưu thời gian hoàn thành tác vụ chính.

## Màu sắc khuyến nghị
- Primary: #0F766E
- Secondary: #2563EB
- Success: #16A34A
- Warning: #F59E0B
- Danger: #DC2626
- Neutral text: #0F172A, border: #E2E8F0, background: #F8FAFC

## Typography
- Font: Inter hoặc tương đương sans-serif.
- Kích thước:
  - H1: 28/36
  - H2: 24/32
  - H3: 20/28
  - Body: 16/24
  - Small: 14/20

## Spacing & layout
- Spacing scale: 4, 8, 12, 16, 24, 32, 48.
- Radius: card 10px, input 8px.
- Desktop 12 cột, mobile 4 cột.

## Component rules
- Nút: Primary, Secondary, Ghost, Destructive.
- Form: luôn có helper text + lỗi inline.
- Bảng: có filter, sort, phân trang.
- Modal xác nhận cho tác vụ phá hủy dữ liệu.

## Badge trạng thái
- `dang_cho`: xám/xanh nhạt.
- `da_thanh_toan`: xanh dương.
- `da_xac_nhan`: teal.
- `da_hoan_tat`: xanh lá.
- `da_huy`: đỏ.
- `khong_den`: cam.

## UX copy tiếng Việt
- Lỗi hợp lệ email: "Vui lòng nhập email hợp lệ."
- Lỗi số điện thoại: "Số điện thoại phải gồm 10 chữ số."
- Lỗi item đặt lịch: "Vui lòng chọn ít nhất 1 mục dịch vụ/gói khám."
