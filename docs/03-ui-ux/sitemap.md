# Sitemap

## Public
- Trang chủ
- Danh sách chuyên khoa
- Danh sách bác sĩ
- Danh sách dịch vụ/gói khám
- Tra cứu lịch hẹn nhanh
- Đăng nhập
- Đăng ký

## Patient
- Dashboard bệnh nhân
- Đặt lịch (4 bước)
- Lịch hẹn của tôi
- Đổi lịch
- Hủy lịch
- Hồ sơ cá nhân
- Lịch sử khám
- Tài liệu hồ sơ bệnh án

## Staff (Nhân viên/Lễ tân)
- Dashboard lễ tân
- Tạo bệnh nhân walk-in
- Tra cứu bệnh nhân
- Đặt lịch hộ
- Danh sách lịch hẹn trong ngày
- Check-in

## Doctor
- Dashboard bác sĩ
- Lịch làm việc
- Danh sách lịch hẹn theo ngày
- Phiếu khám
- Chỉ định dịch vụ
- Kê đơn thuốc
- Tài liệu hồ sơ bệnh án

## Admin
- Dashboard admin
- Quản lý người dùng
- Vai trò và quyền
- Chuyên khoa
- Phòng khám
- Dịch vụ
- Gói khám
- Ca làm việc mẫu
- Cấu hình hệ thống
- Báo cáo
